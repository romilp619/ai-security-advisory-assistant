# Dependency scan demo

This is a synthetic npm lockfile for testing the advisory lookup UI. It is not an installed application and must not be used as a dependency template. The deliberately old versions are lodash 4.17.20, minimist 1.2.5, qs 6.7.0, and express 4.17.1. Upload package-lock.json in the Dependencies tab; do not run npm install from this folder. Advisory results depend on the current OSV.dev source.
